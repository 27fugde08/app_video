# CreatorOS Desktop - Portable Tools Manifest

This directory contains bundled portable binaries and Python CLI runtimes extracted from Simple Tikdown V2 / multitool_py_cli:

1. tools/ffmpeg/
   - ffmpeg.exe & ffprobe.exe (NVENC & libass hardware accelerated build)
2. tools/multitool/
   - multitool_cli.exe & _internal/ (Faster-Whisper ctranslate2, vietnormalizer, librosa, paddle)
